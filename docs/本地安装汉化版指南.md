# OpenSpec 汉化版本地安装指南

## 重要说明

⚠️ **不要使用 `npm install -g @fission-ai/openspec`！**

那样会安装原版的英文版本，而不是我们汉化的版本。

---

## 安装方式对比

| 方式 | 命令 | 版本 | 适用场景 |
|------|------|------|---------|
| ❌ NPM 全局安装 | `npm install -g @fission-ai/openspec` | 英文原版 | 不适用（会覆盖汉化版） |
| ✅ 本地构建安装 | `pnpm install && pnpm build && npm link` | 汉化版 | **推荐使用** |
| ✅ 直接运行 | `node /path/to/openspec/bin/openspec.js` | 汉化版 | 临时使用 |

---

## 方式一：本地构建并全局链接（推荐）

### 步骤 1：构建项目

```bash
# 进入 OpenSpec 汉化版目录
cd d:\AI\openspec

# 安装依赖（如果还没安装）
pnpm install

# 构建项目
pnpm build
```

**验证构建**：
```bash
# 检查 dist 目录是否存在
ls dist

# 应该看到：
# dist/
# ├── cli/
# ├── core/
# ├── utils/
# └── ...
```

### 步骤 2：全局链接

```bash
# 在 OpenSpec 目录中执行
npm link
```

**这个命令会**：
1. 在全局 npm 目录创建符号链接
2. 链接到当前目录的 `bin/openspec.js`
3. 使 `openspec` 命令在任何地方都可用

### 步骤 3：验证安装

```bash
# 检查版本
openspec --version

# 检查帮助（应该是中文）
openspec --help

# 应该看到中文输出：
# 用法: openspec [选项] [命令]
# 
# OpenSpec - 为 AI 编码助手提供规范驱动开发
# ...
```

### 步骤 4：测试功能

```bash
# 创建测试目录
mkdir test-project
cd test-project

# 初始化（应该看到中文提示）
openspec init

# 应该看到：
# ✔ OpenSpec 初始化成功！
```

## 方式二：创建全局别名

如果 `npm link` 不工作，可以创建别名。

### Windows (PowerShell)

#### 临时别名（当前会话）

```powershell
# 创建别名
function openspec { node d:\AI\openspec\bin\openspec.js $args }

# 测试
openspec --version
```

#### 永久别名（推荐）

```powershell
# 1. 打开 PowerShell 配置文件
notepad $PROFILE

# 如果文件不存在，先创建
if (!(Test-Path -Path $PROFILE)) {
  New-Item -ItemType File -Path $PROFILE -Force
}

# 2. 在配置文件中添加以下内容
function openspec { node d:\AI\openspec\bin\openspec.js $args }

# 3. 保存并重新加载配置
. $PROFILE

# 4. 测试
openspec --version
```

### Linux/macOS (Bash/Zsh)

```bash
# 1. 编辑 shell 配置文件
# Bash 用户
nano ~/.bashrc

# Zsh 用户
nano ~/.zshrc

# 2. 添加别名
alias openspec='node /path/to/openspec/bin/openspec.js'

# 3. 重新加载配置
source ~/.bashrc  # 或 source ~/.zshrc

# 4. 测试
openspec --version
```

## 方式三：直接运行（不推荐）

如果不想全局安装，可以每次都指定完整路径：

```bash
# Windows
node d:\AI\openspec\bin\openspec.js init

# Linux/macOS

```

**缺点**：
- ❌ 每次都要输入完整路径
- ❌ 不方便
- ❌ AI 工具可能无法直接调用

## 常见问题

### Q1: `npm link` 后仍然是英文版？

**可能原因**：
- 之前安装过全局的英文版

**解决方法**：
```bash
# 1. 卸载全局的英文版
npm uninstall -g @fission-ai/openspec

# 2. 重新链接汉化版
cd d:\AI\openspec
npm link

# 3. 验证
openspec --version
openspec --help  # 应该是中文
```

### Q2: 修改代码后没有生效？

**原因**：
- 没有重新构建

**解决方法**：
```bash
cd d:\AI\openspec
pnpm build
# npm link 会自动使用最新构建
```

### Q3: PowerShell 提示无法加载配置文件？

**原因**：
- PowerShell 执行策略限制

**解决方法**：
```powershell
# 以管理员身份运行 PowerShell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

# 然后重新加载配置
. $PROFILE
```

### Q4: 如何在多台电脑上使用汉化版？

**方法 1：Git 同步**
```bash
# 在每台电脑上
git clone https://github.com/Fission-AI/OpenSpec.git
cd OpenSpec
git checkout zh-cn-lite  # 切换到汉化分支
pnpm install
pnpm build
npm link
```

**方法 2：打包分发**
```bash
# 在主电脑上
cd d:\AI\openspec
pnpm pack
# 生成 fission-ai-openspec-x.x.x.tgz

# 在其他电脑上
npm install -g /path/to/fission-ai-openspec-x.x.x.tgz
```

## 总结

### ✅ 推荐方式

**使用 `npm link` 全局链接汉化版**：
```bash
cd d:\AI\openspec
pnpm install
pnpm build
npm link
```

**优点**：
- ✅ 全局可用
- ✅ 自动使用最新构建
- ✅ 方便更新
- ✅ AI 工具可以直接调用

### ❌ 不推荐方式

**通过 npm 安装原版**：
```bash
npm install -g @fission-ai/openspec  # ❌ 不要这样做！
```

**原因**：
- ❌ 会安装英文原版
- ❌ 覆盖汉化版
- ❌ 失去汉化效果
