## 工具使用方式

### 方式 1：使用 --tools all
```bash
openspec init --tools all
```
- 生成所有 15 个工具的配置
- 适合团队使用多种 AI 工具的场景

### 方式 2：使用 --tools none
```bash
openspec init --tools none
```
- 只生成基础的 AGENTS.md
- 适合不使用特定 AI 工具的场景

### 方式 3：选择特定工具
```bash
openspec init --tools "claude,cursor,auggie"
```
- 只生成指定工具的配置
- 适合个人或小团队使用固定工具的场景

## 共存机制

### 文件隔离
每个工具的配置文件都在独立的目录中：
- `.augment/` - Auggie 专用
- `.claude/` - Claude Code 专用
- `.cursor/` - Cursor 专用
- `.github/` - GitHub Copilot 专用
- 等等...

### 无冲突
- 不同工具的配置文件互不干扰
- 可以同时安装多个工具的配置
- 每个工具只读取自己的配置目录

### 共享核心
所有工具共享：
- `openspec/AGENTS.md` - 核心工作流指令
- `openspec/project.md` - 项目上下文
- `openspec/changes/` - 变更提案目录
- `openspec/specs/` - 规范目录
